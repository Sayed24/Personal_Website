# ⚡ Quick Start Guide

Get your dynamic website up and running in 5 minutes!

## 🎯 Step-by-Step Setup

### Step 1: Access Admin Panel (30 seconds)
```
1. Go to your website
2. Click the ⚙️ icon in the top-right corner
   OR press Ctrl+Shift+A
3. Admin panel opens!
```

### Step 2: Add Your First Project (1 minute)

1. **Click "Projects" tab**
2. **Fill in the form:**
   - Title: `My Awesome Project`
   - Description: `A cool project I built`
   - Technologies: `HTML, CSS, JavaScript`
   - Category: `HTML/CSS/JS`
   - Colors: Pick any colors you like
3. **Click "Add Project"**
4. ✅ Project appears on your site instantly!

### Step 3: Update About Section (30 seconds)

1. **Click "About" tab**
2. **Edit the text** about yourself
3. **Click "Update About"**
4. ✅ Changes appear in the About section!

### Step 4: Add Skills (1 minute)

1. **Click "Skills" tab**
2. **Add a skill:**
   - Name: `JavaScript`
   - Icon: `🚀` (or any emoji)
3. **Click "Add Skill"**
4. ✅ Skill appears in About section!

### Step 5: Create Blog Post (1 minute)

1. **Click "Blog" tab**
2. **Fill in:**
   - Title: `My First Blog Post`
   - Content: `<p>Hello, this is my first post!</p>`
   - Tags: `blog, first, hello`
3. **Click "Add Post"**
4. ✅ Blog post appears in Blog section!

## 💾 Backup Your Data (Important!)

### Export (Save Backup)
1. Open Admin Panel
2. Click "Backup" tab
3. Click "📥 Export Data (JSON)"
4. File saves to your computer
5. ✅ You have a backup!

### Import (Restore Backup)
1. Open Admin Panel
2. Click "Backup" tab
3. Click "📤 Import Data (JSON)"
4. Select your backup file
5. ✅ Data restored!

## ⚙️ Advanced Customization

### Change Colors
Edit `styles.css`:
```css
:root {
    --primary-warm: #YOUR_COLOR;
    --accent-green: #YOUR_COLOR;
    --accent-blue: #YOUR_COLOR;
}
```

### Change Font
Edit `styles.css`:
```css
:root {
    --font-main: 'Your Font', sans-serif;
}
```

### Add More Project Categories
1. Edit `index.html` - add filter button
2. Add projects with that category
3. Done!

## 🐛 Quick Troubleshooting

| Problem | Solution |
|---------|----------|
| Nothing saves | Check if localStorage is enabled |
| Form won't submit | Check all fields are filled |
| Dark mode not saving | Clear cache and try again |
| Projects disappeared | Look for export backup file |
| Admin panel won't open | Press Ctrl+Shift+A or refresh page |
